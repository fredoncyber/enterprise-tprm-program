# Endpoint Security Vendor Evidence Request

Request only what is applicable and protect vendor confidential information.

- Architecture and data-flow diagrams, agent privilege model and tenant isolation
- Supported OS/platform matrix and lifecycle policy
- Secure development and release/update pipeline description
- Code-signing, key protection, staged rollout, rollback and kill-switch controls
- SBOM/VEX availability and dependency management
- Independent assurance reports and penetration-test summary
- Vulnerability disclosure, remediation SLAs and security advisories
- Telemetry fields, data residency, retention, customer controls and AI/model usage
- Administrative access, support access, MFA/PAM and audit logging
- Detection-content governance, testing and false-positive safeguards
- Cloud control-plane resilience, regional design, RTO/RPO and DR results
- Incident-response plan, notification commitments and prior material lessons learned
- Critical fourth parties and hosting dependencies
- Portability, API/export, agent uninstall, data deletion and termination support
