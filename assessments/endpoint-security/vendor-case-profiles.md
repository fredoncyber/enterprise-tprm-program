# Endpoint Security Vendor Case Profiles

These profiles define **assessment focus areas**, not conclusions. Product capabilities, corporate structures and service terms change; analysts must validate current official documentation and evidence.

| Company | Illustrative platform family | Analyst emphasis |
|---|---|---|
| CrowdStrike | Falcon endpoint security / XDR | Sensor and content-update governance, staged rollout, recovery, cloud-console dependency, telemetry, MDR boundaries and fourth-party concentration. |
| SentinelOne | Singularity endpoint / XDR | Autonomous remediation safeguards, rollback behavior, agent privileges, AI data usage, console identity, policy testing and MDR scope. |
| Microsoft | Defender for Endpoint / Defender XDR | Microsoft 365/Azure dependency concentration, tenant configuration, licensing boundaries, identity integration, data residency, portal resilience and shared responsibility. |
| Palo Alto Networks | Cortex XDR / XSIAM | Cross-domain data lake, agent policy safety, integrations, SOC automation, telemetry scope, cloud dependency and platform concentration. |
| Broadcom | Symantec Endpoint Security / Carbon Black portfolio | Product roadmap, support model, portfolio integration, agent lifecycle, management-plane architecture, licensing and exit portability. |
| Fortinet | FortiEDR and Security Fabric integrations | Endpoint-network integration blast radius, FortiGate/FortiManager dependencies, policy orchestration, telemetry sharing and segmentation. |
| Trend Micro | Trend Vision One / endpoint and workload security | Endpoint/container/workload boundaries, multi-cloud integrations, data lake/telemetry, update pipeline, product modules and regional processing. |
| Sophos | Sophos Endpoint / Central / MDR | Synchronized-security dependencies, cloud console, policy isolation, MDR responsibilities, agent update controls and recovery. |
| Cisco | Secure Endpoint / broader security platform | Talos/intelligence and platform integrations, identity/network dependencies, connector privileges, telemetry, API security and product transition risk. |
| Bitdefender | GravityZone endpoint security | Cloud/on-prem management options, agent performance, risk analytics, update safety, MDR boundaries, data processing and migration support. |

## Standard evidence package for all ten
- Current architecture, data flow, subprocessors and service locations
- SOC 2 Type II or equivalent scope and exceptions
- ISO certifications where relevant, with statement of applicability/scope
- Secure-development and update-pipeline controls
- Independent detection/prevention evaluations and limitations
- Most recent penetration-test executive summary
- Incident, vulnerability and advisory history relevant to the subscribed service
- Business continuity and disaster recovery test evidence
- Privacy/data-processing terms and telemetry dictionary
- Customer responsibility matrix
- Product roadmap, end-of-life policy and exit process

## Analyst caution
Do not infer control effectiveness from brand size, market position, certifications, benchmark scores, AI claims, or prior experience. Validate the exact licensed modules, tenant, region, configuration, deployment ring, support/MDR model and contractual commitments.
